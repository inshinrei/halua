# Halua 5.0.0

**Date:** 2026-08-17

Log-driven development on the default logger, a typed feature builder, and stamp timers that return elapsed milliseconds.

Upgrade guide (copy-paste companion): [Migrating from 4.1.0 to 5.0.0](../migrations/4.1.0-to-5.0.0.md). The same file ships in the npm package at `lib/migrations/4.1.0-to-5.0.0.md`.

## Install

```bash
pnpm add halua@5.0.0
# or: npm install halua@5.0.0
```

## Highlights

- Default `halua` includes `.flow(name, ctx?)` and `.span(label, fn?)` for a stable, grepable work mark.
- New `createHalua()` fluent builder with `.use(feature)` and accumulating TypeScript capabilities.
- Opt-in `capture()` — `collect()` / `clear()` of raw dispatch records for asserting the log story.
- `.stamp` / `.stampEnd` return raw elapsed ms (`performance.now` delta). The pretty `took X.XXms` line is unchanged.
- Migration guides now ship inside the package (`lib/migrations/`), next to `lib/AGENTS.md`.

## New

- `createHalua()` — `.dispatchers`, `.level`, `.redact`, `.withArgs`, `.use`, `.build`.
- `spanFlow()` — `.flow` is `child("flow", name, …flattened ctx)`. `.span` logs `start` / `done` with `{ span, elapsedMs }` on a `span <label>` child; on throw it logs `.error` or `never-happen` and rethrows. Ender form `span(label)` returns `() => number`.
- `capture()` — feature dispatcher records `{ timestamp, level, args, errorMeta? }`. Shared buffer across parent and children.
- Exports: `HaluaBuilder`, `Feature`, `SpanFlowApi`, `CaptureApi`, `CapturedRecord`.
- `HaluaLogger<ErrorMeta, Caps = {}>` — features attach as `Caps`.
- Features stored on the instance are re-applied in `.child()` / `.create()`. They may add methods and optional dispatchers. They are **not** dispatch middleware.

## Changed

- Default export construction: `createHalua().dispatchers(NewConsoleDispatcher(console)).use(spanFlow()).build()` instead of `new Halua(...)`.
- `.create()` / `.child()` inherit the parent’s feature list (so a logger from `halua.create(NewTextDispatcher(...))` still has `.flow` / `.span`).
- `stamp(label, id?)` ender: `() => void` → `() => number`. Re-calling the ender returns the cached duration and does not log again.
- `stampEnd(id)`: `void` → `number | undefined`.

## Compatibility

- **No JSON shape change.** Records stay `{ timestamp, level, args }`.
- **No `DispatcherExecuteMeta` change.**
- Existing `halua.create(dispatchers?, options?)`, child context, dispatchers, levels, redaction, and `errorMeta` behavior are unchanged.
- Typical 4.1.0 applications compile and run without edits.
- Soft breaks: reserved child keys `flow` and `span`; stamp return types; default instance now has two extra methods.

Not in this release: object-form `.child({})`, JSON `ctx` separate from `args`, OpenTelemetry, instance `.use()` after `build()`, `.start()` / `.done()` methods.
